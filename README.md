# Claude Skills

Skills que uso no meu trabalho com dados, processos e automação, abertas para quem quiser usar ou adaptar.

| Skill | O que faz |
|---|---|
| [relational-db-design](relational-db-design/) | Modela um banco de dados relacional do zero, a partir de entrevistas, planilhas ou uma base existente, seguindo o método do livro *Grokking Relational Database Design*. Termina com o diagrama entidade-relacionamento e um roteiro para o Claude Code criar o banco no Supabase. |
